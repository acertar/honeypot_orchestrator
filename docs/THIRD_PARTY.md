# Сторонние компоненты и лицензии

Frontend-ассеты лежат локально в `backend/app/static/vendor/` и не требуют CDN.

| Компонент | Версия | Лицензия | Назначение |
|---|---|---|---|
| Alpine.js | 3.14.1 | MIT | реактивность UI |
| ECharts | 5.5.1 | Apache-2.0 | графики и карта |
| Socket.IO client | 4.8.1 | MIT | live-лента |
| Tailwind CSS | 3.4.17 (build) | MIT | utility CSS |
| Manrope (variable) | Fontsource 5.2.5 | OFL-1.1 | основной шрифт |
| JetBrains Mono (variable) | Fontsource 5.2.5 | OFL-1.1 | monospace |
| World map GeoJSON | ECharts 4.9 map data | Apache-2.0 | карта атак |

Backend-зависимости перечислены в `backend/requirements.txt`; их лицензии —
в соответствующих пакетах PyPI.
